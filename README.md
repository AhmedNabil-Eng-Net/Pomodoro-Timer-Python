# ⏳ Python Pomodoro Timer

A simple command-line Pomodoro Timer built with Python.

## Features

* Set a timer in minutes
* Display the remaining time in `MM:SS` format
* Validate user input
* Show an animated message for invalid input
* Notify the user when the timer ends

## Technologies

* Python
* `time` module

## How to Run

Make sure Python is installed on your computer.

Run the program with:

```bash
python main.py
```

## How It Works

1. Enter the timer duration in minutes.
2. The program converts the time into seconds.
3. The timer counts down and displays the remaining time.
4. When the timer reaches zero, a notification is displayed.
